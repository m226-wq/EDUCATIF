# قناة مستجدات التربية — فيديوهات قصيرة تلقائية (يوتيوب Shorts + إنستغرام Reels)

3 فيديوهات يومياً، كل واحد في وقت مختلف، بلا تدخل منك:

| التوقيت (المغرب) | النوع |
|---|---|
| 07:00 | اختبار اختيار من متعدد (QCM) مع الجواب الصحيح وشرحه |
| 13:00 | سؤال وجواب حول مستجد علمي |
| 19:00 | اقتراحات تطبيقية للأستاذ في القسم |

## كيف يعمل
1. **جمع**: مجلات محكّمة (Crossref)، ERIC، Edutopia، OECD، UNESCO، The Conversation.
2. **اختيار** (Groq): ترتيب المواد حسب صلتها بمهنة التدريس.
3. **كتابة** (Groq): سيناريو عربي من نص المصدر فقط، وQCM يُبنى برمجياً مع خلط عشوائي لموضع الجواب.
4. **تدقيق علمي آلي** (Groq): مرور ثانٍ يرفض أي ادعاء غير مسنود بالمصدر، ويُعاد الكتابة أو يُستبدل الموضوع.
5. **فحوص برمجية**: عدد الكلمات، منع الحروف اللاتينية في النص المنطوق، توحيد الأرقام إلى 0-9.
6. **فيديو**: صوت عربي (edge-tts)، ترجمة متزامنة مع الصوت، عدّاد تنازلي 5-4-3-2-1 قبل كشف الجواب، موسيقى خلفية هادئة.
7. **نشر** على يوتيوب وإنستغرام، وحفظ السجل لتفادي التكرار.

كل شيء مجاني: GitHub Actions + Pages (مستودع **عام**) + Groq (الطبقة المجانية) + edge-tts.

## الإعداد (مرة واحدة)

### 1) المستودع
أنشئ مستودعاً **عاماً**، ارفع الملفات، ثم `Settings → Pages → Source: GitHub Actions`. عدّل `config.yml`.

### 2) Groq
من https://console.groq.com/keys أنشئ مفتاحاً مجانياً وأضفه في `Settings → Secrets and variables → Actions` باسم `GROQ_API_KEY`.
النماذج المعرّفة في `config.yml` تُجرَّب بالترتيب؛ إن استُنفدت حصة نموذج ينتقل تلقائياً للتالي (أسماء النماذج تتغير أحياناً، راجع https://console.groq.com/docs/models وحدّثها إن لزم).

### 3) يوتيوب
1. في Google Cloud أنشئ مشروعاً وفعّل **YouTube Data API v3**.
2. أنشئ OAuth client نوع **Desktop app** ونزّل `client_secret.json` في جذر المشروع.
3. اجعل شاشة الموافقة **In production** (وإلا ينتهي الـ refresh token بعد 7 أيام).
4. محلياً: `pip install google-auth-oauthlib` ثم `python tools/get_youtube_token.py`، وانسخ القيم إلى Secrets: `YT_CLIENT_ID` و`YT_CLIENT_SECRET` و`YT_REFRESH_TOKEN`.
5. المشاريع الجديدة غير الموثّقة تُنشر فيديوهاتها **خاصة** حتى تجتاز مراجعة YouTube API Compliance Audit (مجانية، تأخذ أياماً).

### 4) إنستغرام
حساب Professional مربوط بصفحة فيسبوك، وتطبيق في developers.facebook.com بصلاحيتي `instagram_basic` و`instagram_content_publish`.
أضف `IG_ACCESS_TOKEN` (طويل الأمد، 60 يوماً، جدّده قبل انتهائه) و`IG_USER_ID`.

### 5) التجربة
`Actions → edu-shorts → Run workflow` بـ `dry_run = true`، ثم حمّل الفيديوهات من Artifacts وراجعها. بعدها `false`.

## تخصيص
- **موسيقى**: ضع ملفات mp3 حرة الحقوق في `assets/music/` (وإلا تُولَّد موسيقى هادئة).
- **الصوت**: غيّر `voice` في `config.yml` (`edge-tts --list-voices | grep ar-`).
- **المصادر**: أضف مجلات (ISSN) أو روابط RSS في `config.yml`.
- **اختبار محلي للتركيب**: `FONT_PATH=/path/to/arabic.ttf python tests/smoke_render.py`.

- نستعمل العناوين والملخصات مع نسبة المصدر، والوصف يتضمن إفصاح الذكاء الاصطناعي.
